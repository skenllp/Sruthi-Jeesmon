# Jees & Sruthi – Betrothal Ceremony

Static website (HTML / CSS / JavaScript). No build step.

**Betrothal & Reception – Sunday, 27 December 2026**

## Deploy
Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel…).

## Before sharing on WhatsApp (important)
Open Graph previews need absolute URLs. Once you know your final address, run:

    ./set-domain.sh https://your-final-domain.com

(or search & replace `https://YOUR-DOMAIN-HERE` in `index.html`). Then re-share the link; if WhatsApp
shows an old preview, paste the link into https://developers.facebook.com/tools/debug/ and click "Scrape Again".

## Files
